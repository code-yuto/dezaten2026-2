# 機能要件

- 作品名（仮）：てのあと
- テーマ：破壊と創造
- 展示：デザ展（2027年2月）、机の上に置く常設展示

## コンセプト

手を開いて置くと、その形が光として残る。
手を握ると、前の人たちの手形がすべて消える。

握るのは自然な動き。手を抜くとき、多くの人は無意識に指を閉じる。
だから消した本人は、自分が誰かのデータを消したことに気づかない。

## 体験の流れ

1. 暗い箱の中に、前の人たちの手形がうっすら光っている
2. 手を開いて入れると、その手の形が光る
3. 手を抜こうとして指を閉じると、前の人たちの手形がすべて消える
4. 自分の手形だけが残り、少しずつ消えていく
5. 次の人が来て、同じことが繰り返される

## 入力と出力

- 入力：箱に入れた手
- 出力：天板の下の紫外線LEDで蓄光シートを光らせる
- モニターやプロジェクターは使わない

## 機能一覧

| ID | 機能 | 内容 | 優先度 |
|---|---|---|---|
| FR-01 | 手の検出 | 箱に手が入ったこと、出たことを検出する | 必須 |
| FR-02 | 手の形の取得 | 手のシルエットを取り、LEDの並びに合わせた点の集まりに変換する | 必須 |
| FR-03 | 開く・握るの判定 | 手が開いているか、握っているかを判定する | 必須 |
| FR-04 | 手形を残す（創造） | 開いた手の形の位置にあるLEDだけを点け、蓄光シートに手形を残す | 必須 |
| FR-05 | 消す（破壊） | 握ったら、前の人たちの手形をすべて消す。自分の手形は残す | 必須 |
| FR-06 | リセット | かすかな残光がたまったら、誰もいないときに全体を光で埋めて均一にする | 必須 |
| FR-07 | 調整 | 明るさ、点灯時間、リセットの間隔、判定のしきい値を、コードを書き換えずに変える | 必須 |
| FR-08 | 手形の記録 | 取得した手形を保存する | あれば良い |
| FR-09 | 待機中の演出 | しばらく誰も来ないとき、記録した手形をときどき光らせる | あれば良い |

## 各機能の補足

### FR-02 手の形の取得
- 指の形がわかる細かさにする
- 手首から先だけを使う。腕の部分は光らせない

### FR-03 開く・握るの判定
- 手を抜くときに指を軽く閉じる程度の、無意識の動きでも「握る」と判定する

### FR-04 手形を残す
- 手を入れている間、手の形に合わせて光らせ続ける
- 手を動かしたら、動いた跡も残る

### FR-05 消す
- 蓄光は暗くできないので、全体を光で埋めて手形の形を見えなくすることで消す
- そのあと自分の手形の部分をさらに強く光らせ、自分の手形だけを残す
- 波や音のような目立つ演出はしない。何が起きたか気づかれないようにする
- 記録した手形（FR-08）も消す
- 展示の説明に「握ると消える」とは書かない

### FR-06 リセット
- 間隔は展示で試して決める
- 人が手を入れている間は行わない

## 決まっていないこと

- 手の検出方法：赤外線カメラで上から見るか、天板の下にセンサーを並べるか
- LEDの間隔と個数
- 光らせる面の大きさ
- 握ったとき、自分の手形も一緒に消すか（今は残す想定）
- 握ってから消えるまでの間（すぐ消すか、少し遅らせて気づかれにくくするか）
- 音を付けるか
