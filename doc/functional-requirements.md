# 機能要件

- 作品名（仮）：てのあと
- テーマ：破壊と創造
- 展示：デザ展（2027年2月）、机の上に置く常設展示

## コンセプト

手を開いて置くと光が生まれ、握ると光が壊れる。
壊れたあとの光の破片が、次の人の手形の下地になる。

蓄光は光をためて、少しずつ失っていく素材。作ったものは必ず消える。

## 体験の流れ

1. 暗い箱の中に、前の人の手形がうっすら光っている
2. 手を開いて入れると、その手の形が光る
3. 手を抜いても手形は残り、少しずつ消えていく
4. 手を握ると、握った位置から光の波が広がり、手形が崩れる
5. 手形が一定の数たまると、誰も握らなくても崩れて最初に戻る

## 入力と出力

- 入力：箱に入れた手
- 出力：天板の下の紫外線LEDで蓄光シートを光らせる
- モニターやプロジェクターは使わない

## 機能一覧

| ID | 機能 | 内容 | 優先度 |
|---|---|---|---|
| FR-01 | 手の検出 | 箱に手が入ったこと、出たことを検出する | 必須 |
| FR-02 | 手の形の取得 | 手のシルエットを取り、LEDの並びに合わせた点の集まりに変換する | 必須 |
| FR-03 | 開く・握るの判定 | 手が開いているか、握っているかを判定する | 必須 |
| FR-04 | 手形を残す（創造） | 開いた手の形の位置にあるLEDだけを点け、蓄光シートに手形を残す | 必須 |
| FR-05 | 崩す（破壊） | 握ったとき、その位置から光の波を広げて今ある手形を崩す | 必須 |
| FR-06 | 自然に崩れる | 手形がN個たまったら、FR-05と同じ崩れる演出を自動で行う | 必須 |
| FR-07 | 調整 | 明るさ、点灯時間、N、判定のしきい値を、コードを書き換えずに変える | 必須 |
| FR-08 | 手形の記録 | 取得した手形を保存する | あれば良い |
| FR-09 | 待機中の演出 | しばらく誰も来ないとき、記録した手形をときどき光らせる | あれば良い |

## 各機能の補足

### FR-02 手の形の取得
- 指の形がわかる細かさにする
- 手首から先だけを使う。腕の部分は光らせない

### FR-04 手形を残す
- 手を入れている間、手の形に合わせて光らせ続ける
- 手を動かしたら、動いた跡も残る

### FR-05 崩す
- 波は握った位置から外へ広がる
- 崩れたあとに残る模様（波紋、破片）も作品の一部として見せる

### FR-06 自然に崩れる
- Nは展示で試して決める（はじめは10で試す）
- 崩れたあとは手形の数を0に戻す

## 決まっていないこと

- 手の検出方法：赤外線カメラで上から見るか、天板の下にセンサーを並べるか
- LEDの間隔と個数
- 光らせる面の大きさ
- 開く・握る以外の手の形を使うか
- 音を付けるか
