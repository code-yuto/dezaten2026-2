# 非機能要件

## 展示環境

- 机の上に置く。大きさは会場を確認してから決める
- 電源はコンセント1口（会場に確認する）
- 会場の明るさは未確認。明るくても手形が見えるよう、箱の中を暗くする
- 展示中は説明する人がいない前提で作る

## 性能

| ID | 項目 | 目標 |
|---|---|---|
| NFR-01 | 手を入れてから光り始めるまで | 0.5秒以内 |
| NFR-02 | 手形が見えている時間 | 1分以上 |
| NFR-03 | 開く・握るの判定 | 10回中9回以上正しく判定する |

## 動き続けること

| ID | 項目 | 内容 |
|---|---|---|
| NFR-04 | 起動 | 電源を入れるだけで、操作なしで体験できる状態になる |
| NFR-05 | 連続稼働 | 展示時間中（1日8時間以上）、止まらずに動く |
| NFR-06 | 復帰 | 止まったら自動で再起動する |
| NFR-07 | 誤動作 | 誤検出が続いても、LEDが点きっぱなしにならない。1つのLEDを連続で点ける時間に上限を設ける |

## 安全

| ID | 項目 | 内容 |
|---|---|---|
| NFR-08 | 紫外線 | 395〜405nmのLEDを使う。光が直接目に入らない構造にする |
| NFR-09 | 熱 | 手が触れる面は40℃を超えない |
| NFR-10 | 手を入れる部分 | とがった角、挟まる隙間、むき出しの配線を作らない |
| NFR-11 | 電源 | 箱の中に100Vを通さない。ACアダプターから低い電圧で給電する |

## 壊れにくさ

- 天板は押されたり叩かれたりしても割れないよう、アクリル板で覆う
- モーターなどの動く部品は使わない
- 配線は箱の中に収め、引っ張られても抜けないよう固定する

## 直しやすさ

- LEDの基板は小さく分け、壊れた部分だけ交換できるようにする
- 調整値は展示中でも変えられるようにする（FR-07）
- 基板、3Dモデル、コードはこのリポジトリで管理する

## 見た目

- 外箱は木で作る
- 基板、配線、カメラなどの機械は外から見せない
- 手を入れる穴と、中をのぞく窓をつける

## 作り方

- 基板：KiCadで設計してJLCPCBに発注する。部品の実装も頼む
- 箱の中の部品（基板の固定具、LEDの間の仕切りなど）：3Dプリント
- 外箱：木材
